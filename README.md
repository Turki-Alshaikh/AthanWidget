## 🌟 نبذة عن التطبيق
**AthanWidget** هو أداة ذكية وأنيقة لسطح المكتب تتيح لك متابعة الوقت المتبقي للصلاة القادمة بكل سهولة. يتميز التطبيق بتصميم عصري (Minimalist & Dark Mode) مستوحى من أدوات Apple (Widgets)، ليبقى بهدوء في خلفية الشاشة دون أن يزعجك أو يغطي نوافذك الأخرى.

## ✨ المميزات الأساسية
- 📍 **تحديد تلقائي للموقع:** يجلب مواقيت الصلاة بدقة بناءً على موقعك الجغرافي دون تدخل منك.
- 🎨 **تصميم عصري وشفاف:** واجهة أنيقة بزوايا دائرية، مع إمكانية التحكم في شفافية الخلفية لتعطي تأثير الزجاج.
- ⚙️ **إعدادات متقدمة (Modern UI):** لوحة تحكم مدمجة لتخصيص الألوان، والشفافية، وتشغيل التطبيق تلقائياً مع نظام Windows.
- 📐 **سحب وتغيير الحجم:** إمكانية تحريك الويدجت في أي مكان على الشاشة، وتغيير حجمه بالسحب من الزاوية (يحفظ آخر مكان وحجم تلقائياً).
- 🔄 **تحديث تلقائي (Auto-Updater):** نظام ذكي للتحقق من التحديثات من GitHub وتحميلها وتثبيتها بنقرة واحدة.
- 🕰 **أرقام مخصصة:** دعم للتبديل بين الأرقام العربية والإنجليزية (١٢٣ / 123).
- tray **System Tray:** يعمل في الخلفية بسلاسة مع أيقونة في شريط المهام للوصول السريع للإعدادات.

## 🚀 طريقة الاستخدام (للعملاء والمستخدمين)
لا حاجة لتثبيت بايثون أو أي برامج أخرى! 
1. اذهب إلى قسم [Releases](../../releases).
2. قم بتحميل أحدث إصدار من ملف `AthanWidget.exe`.
3. شغل الملف واستمتع بالتطبيق! (يمكنك النقر على الزاوية اليمنى السفلية لتغيير حجمه).

## 🛠️ للمطورين (تشغيل الكود المصدري)
إذا كنت مطوراً وترغب في التعديل على المشروع، تأكد من تثبيت المكتبات المطلوبة:

```bash
pip install PyQt6 requests

```

لتشغيل السكربت:

```bash
python AthanWidget.py

```

لتحويله إلى ملف تنفيذي `.exe`:

```bash
pyinstaller --noconsole --onefile --icon=icon.ico --add-data "icon.ico;." AthanWidget.py

```
