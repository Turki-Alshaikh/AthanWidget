# 🇸🇦 العربية

## نبذة عن التطبيق

**AthanWidget** هو تطبيق لويندوز يعرض مواقيت الصلاة والوقت المتبقي للصلاة القادمة مباشرةً على سطح المكتب، من خلال ويدجت عائم بتصميم بسيط وعصري مستوحى من أسلوب الواجهات الحديثة.

يعمل التطبيق بهدوء في الخلفية، ويوفر خيارات لتخصيص مظهر الويدجت، إلى جانب تنبيهات للصلاة وإمكانية تشغيله تلقائياً مع بدء تشغيل Windows.

> **متوفر الآن على Microsoft Store**، ويمكنك تثبيته مباشرةً من متجر مايكروسوفت، أو تنزيل النسخة المستقلة من GitHub Releases.

    <img src="https://img.shields.io/badge/تحميل%20من-Microsoft%20Store-0078D4?style=for-the-badge&logo=microsoftstore&logoColor=white" alt="تحميل AthanWidget من Microsoft Store" />
  </a>
</p>

## المميزات

- 📍 **تحديد الموقع تلقائياً:** يجلب التطبيق مواقيت الصلاة ويحدد اسم المدينة اعتماداً على عنوان IP.
- 🕌 **متابعة الصلاة القادمة:** يعرض الوقت المتبقي للصلاة التالية على سطح المكتب.
- 🕰️ **عرض الوقت بعد الصلاة:** بعد دخول وقت الصلاة، يتحول العداد إلى عرض الوقت المنقضي منذ الصلاة لمدة تصل إلى 30 دقيقة، ثم ينتقل تلقائياً إلى الصلاة التالية.
- 🔔 **تنبيهات قابلة للتخصيص:** إشعارات منبثقة من منطقة النظام، مع إمكانية ضبط تنبيه قبل الأذان، مثل خمس دقائق، وتنبيه عند وقت الأذان.
- 🎨 **تخصيص المظهر:** التحكم في شفافية الخلفية وإخفائها، وإخفاء الحدود وتغيير الألوان، للحصول على مظهر يناسب سطح المكتب.
- 🪟 **ويدجت عائم وقابل لتغيير الحجم:** يمكنك وضع الويدجت على سطح المكتب وتغيير حجمه حسب رغبتك.
- 💾 **حفظ الإعدادات في سجل Windows:** يتم حفظ الإعدادات وموقع الويدجت في سجل ويندوز (Windows Registry)، دون الحاجة إلى ملف إعدادات JSON خارجي.
- 🌐 **الأرقام العربية والإنجليزية:** التبديل بين نمطَي عرض الأرقام من لوحة الإعدادات.
- 🚀 **التشغيل مع بدء Windows:** خيار لتشغيل التطبيق تلقائياً عند تسجيل الدخول إلى ويندوز.
- 🔄 **التحقق من التحديثات:** يتضمن إصدار سطح المكتب آلية للتحقق من التحديثات عبر GitHub وتنزيلها وتطبيقها.
- ⚙️ **لوحة إعدادات حديثة:** واجهة واحدة لإدارة خيارات التطبيق الأساسية.

## التثبيت والتشغيل

يتوفر AthanWidget بطريقتين:

### الطريقة الأولى: Microsoft Store (موصى بها للتثبيت المباشر)

1. افتح صفحة التطبيق على Microsoft Store من الرابط التالي:
   **[AthanWidget على Microsoft Store](https://apps.microsoft.com/detail/9NCS14KCQ1SP)**
2. اضغط على **Get / الحصول** أو **Install / تثبيت** من صفحة المتجر.
3. بعد اكتمال التثبيت، شغّل التطبيق من قائمة Start.

### الطريقة الثانية: GitHub Releases

1. انتقل إلى صفحة [Latest Releases](https://github.com/Turki-Alshaikh/AthanWidget/releases/latest).
2. نزّل أحدث ملف `AthanWidget.exe`.
3. احفظ الملف في المجلد الذي تفضله.
4. شغّل `AthanWidget.exe`.

لا تحتاج إلى تثبيت Python أو مكتبات التطوير لتشغيل ملف EXE الجاهز.

## للمطورين

يمكنك تشغيل المشروع من المصدر أو بناء نسخة تنفيذية بصيغة `.exe`.

### المتطلبات

- تثبيت Python.
- مكتبتا التشغيل `PyQt6` و`requests`، ومكتبة `PyInstaller` عند الرغبة في بناء ملف EXE.
- وجود ملفات المشروع، بما فيها ملف الأيقونة `icon.ico`.

### 1. تثبيت المكتبات

```bash
pip install PyQt6 requests pyinstaller
```

### 2. تشغيل التطبيق من المصدر

```bash
python AthanWidget.py
```

### 3. إنشاء ملف تنفيذي باستخدام PyInstaller

```bash
pyinstaller --noconsole --onefile --icon=icon.ico --add-data "icon.ico;." AthanWidget.py
```

بعد اكتمال عملية البناء، ستجد الملف التنفيذي الناتج داخل مجلد `dist` الذي ينشئه PyInstaller.

- تُحفظ إعدادات التطبيق وموقع الويدجت في Windows Registry.
- قد تختلف طريقة تحديث التطبيق بحسب قناة التثبيت المستخدمة. راجع Microsoft Store أو صفحة GitHub Releases للحصول على الإصدار المناسب.

# 🇺🇸 English

## About

**AthanWidget** is a lightweight Windows desktop application that keeps Islamic prayer times and the countdown to the next prayer visible in a clean, floating widget.

Its modern, minimalist interface sits quietly on your desktop and includes appearance customization, configurable prayer notifications, and an option to launch automatically when Windows starts.

> **AthanWidget is available on the Microsoft Store.** You can install it directly from the Store or download the standalone executable from GitHub Releases.

## Features

- 📍 **Automatic location detection:** Retrieves prayer times and identifies your city using your IP address.
- 🕌 **Next-prayer countdown:** Shows the time remaining until the next prayer directly on your desktop.
- 🕰️ **Elapsed-time display:** After a prayer time begins, the widget can show the time elapsed since that prayer for up to 30 minutes, then move on to the next prayer.
- 🔔 **Configurable notifications:** Displays Windows system-tray notifications, including a customizable reminder before prayer and an alert at prayer time.
- 🎨 **Appearance customization:** Adjust colors and background transparency, hide the background, or remove the border for a cleaner floating-text look.
- 🪟 **Floating and resizable widget:** Keep the widget on your desktop and resize it to suit your workspace.
- 💾 **Windows Registry settings:** Stores application preferences and widget position in the Windows Registry instead of using an external JSON settings file.
- 🌐 **Arabic and English numerals:** Choose your preferred numeral style in the settings panel.
- 🚀 **Start with Windows:** Optionally launch the application automatically when Windows starts.
- 🔄 **Update checks:** The desktop edition includes an update-checking mechanism that uses GitHub to download and apply updates.
- ⚙️ **Modern settings panel:** Manage the main application preferences from one control panel.

## Installation

AthanWidget is available through two installation options.

### Option 1: Microsoft Store

1. Open the [AthanWidget Microsoft Store page](https://apps.microsoft.com/detail/9NCS14KCQ1SP).
2. Select **Get** or **Install** on the Store page.
3. Once installed, launch AthanWidget from the Windows Start menu.

### Option 2: GitHub Releases

1. Open [GitHub Latest Releases](https://github.com/Turki-Alshaikh/AthanWidget/releases/latest).
2. Download the latest `AthanWidget.exe` file.
3. Save it in your preferred folder.
4. Run `AthanWidget.exe`.

The standalone executable does not require a separate Python installation or development dependencies.

## For Developers

You can run AthanWidget from source or package it as a Windows executable.

### Requirements

- Python installed on your system.
- The `PyQt6` and `requests` packages; install `PyInstaller` when building an executable.
- The project files, including `icon.ico`.

### 1. Install dependencies

```bash
pip install PyQt6 requests pyinstaller
```

### 2. Run from source

```bash
python AthanWidget.py
```

### 3. Build a standalone executable with PyInstaller

```bash
pyinstaller --noconsole --onefile --icon=icon.ico --add-data "icon.ico;." AthanWidget.py
```

When the build finishes, the executable will be available in the `dist` directory created by PyInstaller.

## Important Notes

- City detection is based on the IP address, so the detected city may vary depending on the location information associated with your connection.
- Application preferences and the widget position are stored in the Windows Registry.
- The update process may differ depending on the installation channel. Use Microsoft Store or GitHub Releases to obtain the appropriate version.
- When reporting an issue, include your Windows version, AthanWidget version, and the steps needed to reproduce the problem.
